# Built with — logo files

Drop each company's **official** logo here (from its brand / press kit) and the
"Built with" wall picks it up at build time. Until a file exists, the wall shows
the company name as text — never a redrawn logo.

| Company      | File name          | Where to get it                       |
| ------------ | ------------------ | ------------------------------------- |
| Supabase     | `supabase.svg`     | https://supabase.com/brand-assets     |
| Claude       | `claude.svg`       | Anthropic brand / press resources     |
| Claude Code  | `claude-code.svg`  | Anthropic brand / press resources     |
| Vercel       | `vercel.svg`       | https://vercel.com/geist/brands       |
| GitHub       | `github.svg`       | https://github.com/logos              |
| MITRE ATT&CK | `mitre-attack.svg` | MITRE's ATT&CK brand guidance / site  |

Any colour works: the wall turns every logo into one flat tone that follows the
light and dark theme. Follow each company's usage rules.
