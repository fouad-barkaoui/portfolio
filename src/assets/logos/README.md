# Built with — logo files

Each company in the "Built with" row gets one round chip. What goes inside it,
in order of preference:

1. A file you drop here, named after the company's slug (table below). Use the
   company's **official** logo from its brand / press kit.
2. The mark [Simple Icons](https://simpleicons.org) ships for that company
   (CC0), wired up in `src/components/Stack.tsx`.
3. The short text label from `src/content/content.ts` — never a redrawn logo.

| Company      | File name          | Without a file          | Where to get one                      |
| ------------ | ------------------ | ----------------------- | ------------------------------------- |
| Supabase     | `supabase.svg`     | Simple Icons mark       | https://supabase.com/brand-assets     |
| Claude       | `claude.svg`       | Simple Icons mark       | Anthropic brand / press resources     |
| Claude Code  | `claude-code.svg`  | Simple Icons mark       | Anthropic brand / press resources     |
| Vercel       | `vercel.svg`       | Simple Icons mark       | https://vercel.com/geist/brands       |
| GitHub       | `github.svg`       | Simple Icons mark       | https://github.com/logos              |
| MITRE ATT&CK | `mitre-attack.svg` | Text label, "ATT&CK"    | MITRE's ATT&CK brand guidance / site  |

A file is shown as it is, at chip size, so pick one that reads on both the light
and the dark theme. Simple Icons marks use the brand's colour; near-black ones
follow the theme's text colour. Follow each company's usage rules.
